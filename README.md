# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。

## 输入分组（模拟编码器合法按键状态）

在工作台下方的「输入分组」面板，可以把输入开关编入三类组，同一输入可同时属于多个组：

- **一位有效组（ONE_HOT）**：组内恰好一个输入为 1。
- **互斥组（MUTEX）**：组内至多一个输入为 1，允许全为 0。
- **同值联动组（LINK）**：组内所有输入取值相同。

行为约定：

1. 点击开关时，以该次点击的目标取值为固定意图，枚举满足全部分组约束的组合，并选择「其他开关改动数最少」的方案。
2. 若存在多个改动数相同的方案，会在预览中并列展示差异供手动选择，不会按开关遍历顺序暗中选定。
3. 若点击意图与约束冲突，会解释一组足以导致冲突的最小约束条件，且所有开关保持原值。
4. 确认变更时整份文档一次性原子写回，线路、输出与真值表当前行只看到最终的合法组合，不存在短暂的非法中间态。
5. 新增、编辑、删除分组后若当前取值不再合法，会先预览可选的最近合法调整；取消可撤销本次分组增删（删除输入节点触发的成员清理除外）。
6. 目标检测只枚举满足输入约束的组合，并明确列出被排除的组合；约束互相矛盾导致零个合法组合时，不会显示为「全部通过」。
7. 分组信息随实验一起保存到本地存档与导出的 JSON 文件，导入时做完整校验。
